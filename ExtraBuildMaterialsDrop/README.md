# Extra Build Materials Drop

Get more wood and stone for building without multiplying every other item in the world.

The configured multiplier replaces the world's resource modifier for the listed materials when they come from trees and mineable rocks. The same materials from chests, creatures, or other sources are not affected by this mod. Other drops from rocks, such as ores, continue to use the world setting.

The default material multiplier is 2x. Configure `General > Material drop multiplier` in the BepInEx configuration file. Choose 1x, 1.5x, 2x, 2.5x, or 3x. Fractional results are rounded to the nearest whole item for each material.

Supported materials include:
- Wood
- Fine Wood
- Core Wood
- Ancient Bark
- Yggdrasil Wood
- Ashwood
- Stone
- Black Marble
- Grausten

## Why?

Becuase world multipliers adds multipliers for evrey item drop in the world. It doesn't make sense to me to kill a boar and it drops two heads. Besides world multipliers affect metals and other stuff that significantly facilitate item progression. Lastly, trees and rocks simply by their sheer size should drop a little build more.

Are you a builder that think that giant rocks/trees should drop more materials than it currently drops so you can build more, but at at the same time you don't want to affect everything else with whole world multiplier? Than this mod is for you.

If you don't care about whole world multipliers, than simply use it and ignore this mod.
